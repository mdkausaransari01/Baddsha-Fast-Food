## 🌟 **About The Project**

**Baddsha Fast Food** is a modern, fully-responsive order management system designed for a fast food restaurant in Phulwari Sharif, Patna, Bihar. This system allows customers to:

- 🍽️ Browse menu items with prices
- ✅ Select items with portion options (Quarter/Half/Full)
- 📝 Add special requests
- 📧 Receive instant email confirmations
- 📱 Contact restaurant via Call or WhatsApp

The project features a **Dark Coffee Glassmorphism** theme with premium UI/UX, making it visually appealing and user-friendly.
